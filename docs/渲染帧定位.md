# 渲染技术抽查帧定位（24fps）

本表只用于识别正常的既定输出和预期黑场，不用于评价设计、构图、路线或字幕内容。完整范围1～4800帧，共200秒；模型和动画不在本任务中评估或改动。

| 帧 | 技术核验用途 |
| --- | --- |
| 1、121、385 | 确认开头资源加载及无字幕输出 |
| 1849 | 第一次相机切换后的图像加载 |
| 2790、2797、2821 | 季节合成前、黑场峰值、恢复；2797黑场属预期 |
| 2941、2953 | 第二次季节合成峰值与恢复；2941黑场属预期 |
| 3097、4081 | 后段相机切换及反射/材质输出，无花屏或资源缺失 |
| 4537、4753、4800 | 片尾合成输出；4800黑场属预期 |

核验内容限于可解码、没有意外缺帧/错误黑场、既定颜色与合成正确输出。不得从这些抽查推导设计理念是否符合或运镜是否应重做。
