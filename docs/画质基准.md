# 已确认的10秒画质基准

基准文件：`../reference/已确认画质_1080p24_前10秒.mp4`。它来自当前同一clean master的帧1～240，真实10秒、1920×1080、24fps，无字幕/季节标签或音轨。

使用Cycles/OptiX、最高512自适应采样、阈值0.0075、最低32、OpenImageDenoise；12总反弹、4漫反射、8光泽、12透射、16透明；1920×1080、关闭简化、0.5帧运动模糊；AgX Medium High Contrast、曝光-1.0。全部画质参数已固定在`../config/render.json`，新机只更换兼容设备后端。

原电脑RTX4070 Laptop GPU；240帧实际渲染约1小时36分25秒，加编码共1小时36分49秒。中间素材RGB16位PNG，MP4为H.264感知无损档位。这一时间不代表新机耗时，也不是本次截止限制。

原片已验证10秒/240帧/24fps和1080p，解码帧1、49、121、193、240；抽查中文不存在、画面正常。第121帧PNG/MP4的8位RGB平均绝对差约1.105/255，无重复AgX的明显亮度偏移。新机预检先比首帧，完整输出还须检查后半程和季节/片尾，不能用此前10秒证明整片画质全部合格。

真实感仍取决于现有模型和简化的场外背景；本任务只渲染，不擅自重做模型/素材。
